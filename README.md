# Central MX — Credenciales 2026

Presentación web de las credenciales de Central MX, con React, Vite, GSAP ScrollTrigger y Lenis.

## Desarrollo

Requiere Node.js 24.

```sh
npm ci
npm run dev
```

## Validación y producción

```sh
npm run check
npm run preview
```

La compilación se genera en `dist/`. El proyecto incluye configuración para Vercel.

Las imágenes utilizadas están en `public/`. Los documentos fuente y originales de trabajo se conservan localmente, fuera del repositorio.
